# 魔閻 / Shang-Jing Lyu

Personal site and research index. Current work is around reinforcement learning, multi-agent systems, and large language models.

**網站：** [https://moyan-5hx.pages.dev](https://moyan-5hx.pages.dev)

繁中為預設語系。開首頁會進 `/zh`；英文在 `/en`。

## 站上有什麼

| 路徑 | 內容 |
| --- | --- |
| `/zh`、`/en` | 首頁索引 |
| `/about` | 關於 |
| `/academic` | 研究 |
| `/diary` | 文章（日記、筆記、writeup） |
| `/projects` | 作品 |
| `/timeline` | 時間軸 |
| `/friends` | 友站 |

## 本地開發

需要 Node.js 18.18 或以上。

```bash
npm install
npm run dev
```

開 [http://localhost:3000](http://localhost:3000)。

改名字、自介、研究、文章：見 [CONTENT.md](./CONTENT.md)。  
部署與網域：見 [DEPLOY.md](./DEPLOY.md)。

## 技術

Next.js 16（靜態匯出）、Tailwind CSS 4、next-intl、Cloudflare Pages。
